# Python LLM Chatbot

A simple Python application that connects to an LLM using the Groq API.

## Features
- Connects to Groq API using Python.
- Accepts user input through the terminal.
- Generates AI responses using OpenAI GPT-OSS 120B.
- Uses environment variables to securely manage API credentials.

## Technologies
- Python
- Groq SDK
- Python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

Create a `.env` file and add your API key:

```env
GROQ_API_KEY=your_api_key
```

Run the application:

```bash
python main.py
```
