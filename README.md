# Python LLM Chatbot

A simple conversational AI chatbot built with Python and the Groq API, powered by OpenAI GPT-OSS 120B.

## Features
- Groq API integration
- Multi-turn conversations with conversation history
- Customizable system prompt
- Context-aware responses
- Simple terminal-based interface

## Tech Stack
- Python
- Groq API
- OpenAI GPT-OSS 120B
- python-dotenv

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
pip install groq python-dotenv
```

Create a `.env` file and add your API key:

```env
GROQ_API_KEY=your_api_key_here
```

Run the chatbot:

```bash
python main.py
```

## Usage

Ask questions in the terminal. Type `exit` to end the conversation.
